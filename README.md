# HAL KINDERGARTEN（架空の幼稚園サイト）

架空の幼稚園「ハル幼稚園」のウェブサイトを題材にした、ポートフォリオ作品です。
実在する学校法人・園とは関係ありません。

## 公開URL

https://mivork.github.io/hal-kindergarten-portfolio/

## 構成

- `index.html` … トップページ
- `css/` … レスポンシブ対応のスタイル（スマホ・タブレット・PC）
- `js/script.js` … 画面の動き
- `images/` … 画像・アイコン・装飾

## ローカルで表示する

`index.html` をブラウザで開くだけで表示できます。
